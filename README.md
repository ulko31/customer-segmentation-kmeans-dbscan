# Customer Segmentation: KMeans & DBSCAN

**Направление:** Data Analytics / Customer Analytics

Проект по сегментации клиентов интернет-магазина на основе их поведения,
истории покупок и социально-экономических характеристик.

## Цель проекта

Разделить клиентов на группы с похожими характеристиками и определить,
какие сегменты представляют наибольший интерес для бизнеса.

Для сравнения использованы два метода кластеризации:

- KMeans;
- DBSCAN.

## Данные

В анализе используется информация о 1000 клиентах интернет-магазина.

Для сегментации были выбраны признаки, описывающие:

- тип подписки;
- активность на сайте;
- количество предыдущих покупок;
- средний и общий объём покупок;
- доход клиента;
- используемую платформу.

Перед кластеризацией данные были обработаны, закодированы и стандартизированы.

Для уменьшения размерности использован PCA:
7 главных компонент сохраняют около 89,7% исходной дисперсии.

## Стек

Python · pandas · NumPy · scikit-learn · matplotlib

## KMeans

Для выбора количества кластеров были протестированы значения K от 2 до 10.

Оценка проводилась с помощью:

- inertia;
- silhouette score;
- интерпретируемости полученных сегментов.

Итогово было выбрано **5 кластеров**.

### Полученные сегменты

- малоактивные мобильные клиенты;
- активные Basic-клиенты;
- самые ценные клиенты;
- малоактивные desktop-клиенты;
- активные Premium-клиенты.

Наиболее высокая доля покупок наблюдается среди активных Premium-клиентов,
а отдельный небольшой сегмент выделяется высокой покупательской ценностью.

## DBSCAN

Для DBSCAN были протестированы различные значения `eps` и `min_samples`.

Итоговые параметры:

- `eps = 1.4`;
- `min_samples = 10`;
- 3 кластера;
- около 28,4% наблюдений определены как шум.

Анализ показал, что часть объектов, попавших в шум, имеет высокий доход
и заметную историю покупок, поэтому такие наблюдения нельзя автоматически
считать незначимыми или ошибочными.

## Основной вывод

Для задачи клиентской сегментации KMeans оказался более удобным:
метод сформировал понятные бизнес-сегменты и распределил всех клиентов
по группам.

DBSCAN дополнил анализ, позволив обнаружить плотные группы клиентов
и нетипичные наблюдения.

## Возможное применение

Результаты сегментации можно использовать для:

- персонализации маркетинговых коммуникаций;
- отдельных предложений для Premium и Basic-клиентов;
- работы с наиболее ценными покупателями;
- реактивации малоактивных пользователей;
- дальнейшего анализа нетипичных клиентских групп.

Полученные сегменты описывают структуру данных и не доказывают
причинно-следственную связь между принадлежностью к сегменту
и совершением покупки.
